Backup do banco de dados

Exporte um arquivo SQLite com os dados de todas as salas e aulas: cadastros, sessões, respostas, pontuação, relatórios e configurações. Guarde o arquivo em um local seguro.

Restaurar substitui todos os dados atuais pelos dados do arquivo selecionado. Encerre todas as aulas antes de restaurar. Recomendamos baixar um backup atual antes de continuar.
